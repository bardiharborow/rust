A `#[repr]` attribute was applied to a zero-variant enum.

Erroneous code example:

```compile_fail,E0084
#[repr(i32)]
enum NightsWatch {} // error: zero-variant enums do not currently support `#[repr]`
```

Zero-variant enums do not currently support any `#[repr]` attribute. For
example, it is impossible to define an integer type to be used to represent
zero-variant enum values because there are no zero-variant enum values. There
is no way to construct an instance of the following type using only safe code.
So you have two solutions. Either you add variants in your enum:

```
#[repr(i32)]
enum NightsWatch {
    JonSnow,
    Commander,
}
```

or you remove the `#[repr]` attribute from your enum:

```
enum NightsWatch {}
```
